# Shiva Intel App V2

Standalone Streamlit deployment of the rebuilt Shiva Intelligence mobile fantasy-football application.

Streamlit deployment settings:
- Repository: `cmhart13-boop/Shiva-Intell-App-V2`
- Branch: `main`
- Main file path: `app.py`

Add `OPENAI_API_KEY` to Streamlit Secrets to activate Ask Shiva GPT.
